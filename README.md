# 拾年 · 回忆录工作室

一个本地优先的个人回忆录工作台：导入或口述往事，自动补全缺失标题，自行调整时间线和章节分组，加入序与后记，最后导出 HTML、可打印 PDF 或 EPUB 电子书。

项目使用 TypeScript 编写，没有后端。文档解析、标题生成、人物识别、书籍排版和数据备份都在浏览器完成。

## v0.5 视图与排版

界面分成四个独立视图：

- **写作**：默认视图，只保留标题、时间、正文、语音输入和保存状态
- **时间线**：按年份、学段或成书分组总览，支持拖拽、多选、批量改时间和批量删除
- **成书**：选篇、调顺序、设置章节、填写序和后记、生成预览及导出
- **设置与数据**：导入文档、全量导出、自动备份和人物索引

写作视图保持左侧 280px 目录、右侧纸面。界面使用米白、墨色、暖灰和旧木色，无渐变、无彩色填充按钮、无大圆角和明显阴影。标题使用中文衬线字体，UI 使用系统无衬线字体。

成书预览按真实中文 A5 书规格排版：148×210mm 页面、20mm 上下边距、22mm 左右边距、约 104mm 版心、10.5pt 正文、1.65 行距、段首两字缩进。目录带点线和页码，章节、序、后记、人物索引分别起页。

## 功能

### 写作与整理

- 导入 `.txt`、`.md`、`.html`、`.docx`、`.pdf`
- 使用浏览器 Web Speech API 进行中文语音输入，边说边写入正文
- 已有标题原样保留，不会重复生成
- 无标题篇章根据正文关键词和已有标题风格自动拟题
- 模糊时间解析、时间线自动排序、拖拽手动排序
- 全文搜索标题、正文、时间和分组，结果高亮并支持回车跳转
- 单篇编辑、删除、重新拟题和选择是否收录

### 成书与导出

- 按自然年份、中学学年或自定义分组生成章节
- 每篇可填写“成书分组”，如“初中”“高中”“那些人”“那些地方”
- 成书设置包含书名、副标题、作者、序和后记
- 生成封面、书名页、版本页、目录、章节、篇章正文和人物索引
- 下载独立 HTML，或通过浏览器打印为 A4/A5 PDF
- 导出 EPUB，保留目录、自定义分组、序和后记
- 每篇默认留出独立页面，适合纸质书阅读节奏

### 数据安全

- 所有篇目、时间、分组、序和后记导出为 ZIP
- ZIP 内包含 `metadata.json` 和逐篇 Markdown 文件
- 支持 File System Access API 指定本地备份文件夹
- 每次保存后自动将 Markdown 和元数据写入指定文件夹
- 自动迁移旧版 `v1` / `v2` 浏览器数据

## 使用流程

1. 导入文档，或在“手动新增”中直接写作。
2. 在编辑窗口里点击“语音输入”，用中文口述正文；再次点击停止。
3. 检查标题、时间和“成书分组”。没有原标题的内容才会自动拟题。
4. 选择自动时间顺序，或切换到手动顺序拖拽篇章。
5. 在右侧填入书名、作者、序和后记，并选择章节分组方式。
6. 打开“人物索引”，修正误识别、合并不同称呼或手动补充人名。
7. 点击“生成成书预览”，检查目录与排版。
8. 下载 HTML、导出 EPUB，或使用“打印 / 存为 PDF”。
9. 定期点击“导出全部数据 ZIP”，也可连接一个本地文件夹自动备份。

## 语音输入

语音输入使用浏览器的 `SpeechRecognition` / `webkitSpeechRecognition`：

- 识别语言固定为中文 `zh-CN`
- 支持连续识别和临时识别结果
- 最终识别文字追加到正文，临时结果会即时显示
- 需要麦克风权限
- 推荐最新版 Chrome 或 Edge
- 不支持该 API 的浏览器会给出明确提示

## 章节分组

成书提供三种分组方式：

| 模式 | 说明 |
| --- | --- |
| 按自然年份 | 最通用，按时间区间中点所在年份分章 |
| 按中学学年 | 适合校园回忆，8 月后进入新学年，并尝试映射初中/高中 |
| 按我的分组 | 完全使用每篇的“成书分组”字段 |

在“按我的分组”模式下，章节顺序按照分组第一次出现的时间线位置决定，组内顺序沿用当前时间线。切换到手动排序后，分组顺序和组内顺序都会随拖拽结果改变。

## 序、后记与人物索引

- 序和正文之前单独成页。
- 后记位于正文和人物索引之后，同样单独成页。
- 人物识别使用常见姓氏、名字长度、上下文助词和出现次数，不依赖云端模型。
- 默认只把至少出现两次的名字放进索引。
- 可以修改显示名、忽略误识别，或手动补充未识别的名字。
- 书稿末尾自动生成人物索引，列出出现次数和对应篇目。

## 文档导入

| 格式 | 处理方式 |
| --- | --- |
| `.txt` | 直接读取纯文本 |
| `.md` / `.markdown` | 识别标题，清理常用 Markdown 标记 |
| `.html` / `.htm` | 提取标题、段落和列表文字 |
| `.docx` | 浏览器内使用 Mammoth 提取文字和标题层级 |
| `.pdf` | 浏览器内使用 PDF.js 提取文本页 |

标题识别顺序：

1. YAML front matter 的 `title` / `标题`
2. “标题：”“题目：”字段
3. Markdown 一级标题或 Word 标题样式
4. 文档开头的短标题行
5. 文件名中的可读部分
6. 只有以上都没有时，才根据正文生成标题

扫描版 PDF 没有文本层时无法识别正文，需要先做 OCR。

## 时间模型

支持日期、年月、年份、季节、学期、年级和模糊描述：

```text
2018-09-01
2005年6月18日
2018年秋
初二下学期
大概是初三那年冬天
中考前
```

时间会被保存成一个闭区间，而不是伪造的精确日期。排序时依次比较是否可识别、区间中点、起点、终点、时间粒度和可信度。完整规则见 [docs/time-model.md](docs/time-model.md)。

## 数据导出与自动备份

“导出全部数据”会生成：

```text
metadata.json
README.txt
preface.md
afterword.md
entries/
  001-标题.md
  002-标题.md
```

“选择自动备份文件夹”使用 File System Access API：

- 浏览器会要求你指定一个本地文件夹。
- 文件夹句柄保存在 IndexedDB。
- 之后每次保存会防抖写入一份结构化 JSON、逐篇 Markdown、序和后记。
- 浏览器可能因安全策略要求重新授权文件夹。
- 不支持该 API 时仍可使用普通 ZIP 导出。

数据和自动备份都不经过服务器。

```text
src/

  documents/                    TXT/MD/HTML/DOCX/PDF 导入与标题生成
  people/                       人物识别、合并、忽略和索引
  speech/                       Web Speech API 语音输入
  book/

    export-epub.ts              EPUB 3 打包
  storage/
    memory-store.ts             v3 数据模型与旧版迁移
    export-data.ts              全量 ZIP 导出
    directory-backup.ts         本地文件夹自动备份
  main.ts                       页面交互
tests/                          34 项自动化测试
docs/                           时间模型与导入成书架构
```

## 数据与隐私

- 没有后端上传接口。
- 文章保存在浏览器 `localStorage`，键名为 `shinian-memoir:library:v3`。
- 自动备份目录句柄保存在浏览器 IndexedDB。
- 语音识别是否调用浏览器服务由所用浏览器的 Web Speech API 实现决定。
- 清理浏览器站点数据会删除工作台数据，因此重要内容应保留本地文件夹备份或导出 ZIP。

## 首版边界

- 精确到天，不支持时分秒。
- 不支持扫描版 PDF OCR。
- 不支持 Word 图片、表格布局和复杂富文本样式。
- 自动拟题和人物识别都是本地启发式结果，允许人工修正。
- EPUB 以文字书为主，不包含封面图片、脚注编号和出版社级版式。
- 人物识别可能把少数地名或普通词误判成人名，可在索引面板忽略。
